## What's where

- `*.html`: the pages (they stay at the top level, since that's their web address)
- `css/style.css`: all the styles
- `js/`: scripts (loading screen, shooting stars, fish cursor, drag-and-throw, scroll reveal, portfolio posts)
- `img/gallery/`: homepage photo piles
- `img/events/`: events page photos
- `img/icons/`, `img/landing/`, `img/footer/`, `img/cursor/`: everything else on screen
- `audio/`, `fonts/`: sounds and the Bodoni font
- `docs/`: setup notes (shared likes + comments)

Filenames use hyphens instead of spaces, like `img/gallery/book-02.jpg`.
